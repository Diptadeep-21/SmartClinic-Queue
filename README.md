# 🏥 Hospital Queue Management System

## 🚀 Tech Stack

* Frontend: React.js
* Backend: Spring Boot
* Database: MySQL

## ✨ Features

* Patient Registration
* Appointment Booking
* Priority Queue (Normal, Urgent, Critical)
* Emergency Fast-Track 🚨
* Smart Doctor Assignment
* Real-time Queue Updates

## 📂 Project Structure

* `/backend` → Spring Boot API
* `/frontend` → React UI

## ▶️ How to Run

### Backend

* Run Spring Boot app in Eclipse

### Frontend

```bash
cd frontend
npm install
npm start
```
